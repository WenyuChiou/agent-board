# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and assume good faith, keep feedback about the work, and make it easy for anyone, in any language, to take part. Harassment and personal attacks are not accepted.

To report behaviour that breaks this code, contact the maintainer privately through the email address on [their GitHub profile](https://github.com/WenyuChiou). Reports are kept confidential.
