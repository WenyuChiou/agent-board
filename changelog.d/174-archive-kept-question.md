- **A stopped block that still asks is archived by the automatic archive once its three days are over, with its question kept (#174).** Session start, the hourly archive and `--tidy` skipped every block with a visible `[?]` step, so a session that ended with a question left its block in progress.md for ever. After the three days they now take it, but only after the check the explicit archive makes: the ledger holds each question of the block and a copy of it is written for the archive. If that fails, the block stays. The question stays in the ledger and on the pane, under the older unanswered questions. A block within its three days, or whose steps show a `[?]` only inside a code fence, behaves as before. The check is made once for all the blocks of a sweep, and if progress.md changed while it ran (another agent added a `[?]` step, say) the sweep starts again from the new text instead of writing the old one back. Scheduled `--tidy` looks at the sources before it trusts the ledger, so a question asked again in the words of an answered one, before any board saw it, keeps its block. A copy is made only for the questions of the block taken, not for those of another session's block with the same title, and a question whose block is still in the file is never shown as archived, even when the archive stopped half way.
