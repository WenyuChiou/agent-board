- **OpenCode progress reports survive an idle session on Windows (part of #217).** The progress tool and session reports retry once when the runtime ends the reporter call early, using only the time left in the original budget. A real timeout is not retried. Failed progress reports record a fixed code in the hook error log without the report's contents.
  Tests: `an OpenCode report retries once when the runtime ends spawnSync early with ETIMEDOUT`, `an OpenCode report that really times out is not retried`, `an OpenCode report that ends early twice is retried only once`, `a failed OpenCode progress tool logs its code without the payload`.
