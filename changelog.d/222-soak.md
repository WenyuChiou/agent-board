- **A long soak of the terminal board and the page server, with its report (#222).** `tests/e2e/soak.mjs` keeps `--watch` and the `--serve` page running side by side on one isolated world for `--minutes` (1 to 45, default 30). `.github/workflows/soak.yml` runs it weekly and on demand, never per pull request. The soak polls the page 500 ms after each answer and grows the data to the scale budget (100 live sessions, 300 blocks, 1,000 question records). It then archives most tasks through the page's own requests and goes on polling. A probe loaded into the board's own processes counts file operations by kind and requests served, and records memory every 10 seconds. The six audit checks are file operations per poll, server memory, question-file pruning, page-server survival, terminal-board survival and memory levelling. Checks that fail on main because of a known problem are marked with their hold id and fail once they pass. Survival is held only for too few polls while the file-operation check still fails. Every run checks that each archived task is in the month archive file and that nothing else left progress.md. An archive that got no answer in time, or was cut short with nothing lost, and memory after the archive that was too short to measure are held under the same slowness, also only while that check fails; any other refusal or a measured rise fails. A 30-minute run fails any check it could not measure, so a skip never passes the run. They and the run status go to `soak-report.json` and `soak-report.md` after every sample. The world, temp, home and working folders are hidden, and neither the environment nor the page address is written. A bad command line exits 2 with one sentence and creates nothing, and a report folder that cannot be written exits 1 before the run starts. The L0 safety scan now also refuses a built-in module loaded through the module loader.
  Tests: `L6 soak arguments: a rejected --minutes value, a repeated flag and an unknown flag exit 2 with one plain line and create no report folder`, `L6 soak arguments: a report folder that cannot be written exits 1 at once with one plain line and starts no board`, `L6 soak arguments: the redaction replaces the world, temp, home and working folders in both slash styles and any letter case`, `L6 soak arguments: whole minutes from 1 to 45 and an output folder are accepted`, `L6 soak arguments: the report files are written whole, in plain words, with no path, page address or environment in them`, `L6 soak arguments: file operations per poll are the change in operations over the change in requests, per window of samples`, `L6 soak arguments: where each planned task ended up after the archive: archived, still there, or lost`, `L6 soak arguments: an archive with no answer in time, a 408 or one cut short is the known slowness only while file operations fail and nothing was lost`, `L6 soak arguments: an archive refused with an error status or a failed connection fails pruning even while the slowness is held`, `L6 soak arguments: memory after a long archive that was not measured is the known slowness only while file operations fail, and a measured rise still fails`, `L0 safety: no journey helper spawns a process outside the isolated spawn helper`.
