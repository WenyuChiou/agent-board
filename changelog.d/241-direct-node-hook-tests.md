- **The generated Antigravity and Codex hook commands are now tested to reach Node without PowerShell on Windows (#241).** Setup already starts a verified, quote-free Node directly (#445). Running setup again rewrites an older install's PowerShell wrapper as the direct command and leaves other definitions alone. `docs/SETUP.md` describes the direct start and its one fallback. Native-host acceptance and the original intermittent failure stay open in #241.
