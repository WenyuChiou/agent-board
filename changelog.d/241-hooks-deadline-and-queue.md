- **Generated hooks count startup time and queue interrupted events (#241).** The worker counts its Node process startup and, on Windows Antigravity, PowerShell startup against the existing deadline. When enough host time remains, a timed-out or killed reporter saves selected metadata and whether the prompt was a board request, never prompt text, atomically for the next hook to replay through the live-event builder. Replay validates hook arguments and session environment fields, shares the 64-entry queue, uses the worker's start for ordering, and drops events older than the session's last applied millisecond, including Codex events. Session-record renames retry briefly on Windows, and replay removes pending temporary files older than a minute when it can. The generated hook commands change (a shorter start line, and the Antigravity start time on Windows), so Codex asks to trust its hooks again after the next connect.
  Tests: `L5 busy machine: Antigravity and Codex hooks finish under 3 s with 4 CPU-busy processes`, `L4 5 MB file: the Codex hook finishes in under 1 s`, `a hook whose reporter runs past the deadline saves the raw event and the next hook applies it`, `the hook deadline counts from the process start, not from when the worker runs`, `a raw entry with an unknown flag or environment variable is dropped, not applied`, `raw replay classifies board requests and ordinary prompts like live events`, `raw replay accepts clock skew and removes only old pending temporary files`, `unchanged status keeps its board timestamp and retries refused session record renames`, `Windows Antigravity commands fit cmd.exe with a 120 character home path`.
