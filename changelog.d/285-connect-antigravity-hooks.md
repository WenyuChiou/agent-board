- **`/progress connect` hooks Antigravity, not only its skill (#285).** The plugin's connect, by hand or automatic, wrote only the board skill for Antigravity, so none of its turns reached the board. It now writes the installer's four report hooks (session start, prompt, turn end and stop) under its own `agent-board` definition in `~/.gemini/config/hooks.json`, run through a hook worker within Antigravity's 3 s limit (#241), and removes them again on `/progress connect remove`; other tools' definitions keep their bytes. Where `setup-agent --agent antigravity` already hooked it, the connect adds no second set and no worker, and `setup-agent` now takes over the skill file the connect wrote instead of refusing with a conflict, for a progress file in the default folder, in `CLAUDE_CONFIG_DIR`, at `CLAUDE_PROGRESS_FILE` or wherever the connect recorded it; the connect then leaves that skill as it is and never records it as its own. A payload the board refuses is logged with its reason (`REPORTER_FAILED INVALID_SESSION`), from a board in any language. `--codex-doctor --agent <name>` names a host that has the board skill but no report hook: `skill only, no report hook`.
