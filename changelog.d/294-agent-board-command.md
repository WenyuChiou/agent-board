- **A Claude `/agent-board` command opens the live board page (#294).** `/agent-board` starts or reuses the live `--serve` page and replies with its link, in every Claude Code session, and never opens, closes or moves the pane. If the live page cannot start it opens the read-only page, as `/progress` does. `/progress` keeps working as before. The README and the guide name both commands in all three languages.
  Tests: `with a pane surface, /agent-board starts the live board page and leaves the pane open`, `with no pane surface, /agent-board replies with the live board page link and does not try to place the pane`, `/agent-board falls back to the read-only page when the live page cannot start`, `the plugin registers /agent-board beside /progress`.
