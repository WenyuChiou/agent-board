- **Only a conversation a person started is a row; a run an agent started for itself joins its parent's row (#399).** A delegate's `codex exec` or `claude -p`, a subagent and a Codex helper thread now add one line to the row of the session that started them (`+3 runs by Codex, last 20 min ago`) instead of a row each. A run with no known parent is counted only on one folded "Background runs" line, never in the header counts. Two blocks with the same agent and full session id show as one row: the newest wins and the older one is listed under Stopped and may be archived, even while it still looks live. A run is written with the optional marker attributes `origin=run` and `parent=`, documented in `docs/FORMAT.md`; every `progress.md` that is valid today reads and folds as before. Codex is marked from the first record of its own history file (`originator`, `source`, `thread_source`, `parent_thread_id`, the only four fields kept) and, as a hint a later event with a file replaces, from a session that has no history file. Claude Code is marked from print mode. Agents that give no signal (OpenCode, Antigravity, Cursor, Gemini, Grok, Muse, Hermes, OpenClaw, DeepSeek, and any writer that does not add the marker) keep today's rows. No row shows a session id.
