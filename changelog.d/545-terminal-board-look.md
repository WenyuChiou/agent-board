- **Terminal board / looks like the page** · The terminal board looks like the page: the same colours, order and emphasis, no flicker, a board taller than the screen moved to show the line the keys act on, wide symbols measured right in Chinese, and one-key answers to yes/no and two-option questions that say whether they send or only copy, and name the answer once it is sent. It shows the whole way back to a session with the command `c` copies, a Done recently list that `t` archives at once, the agents on an empty board, and prints once as plain text into a pipe. The terminal board and the plain board text now name agents as `Codex` or `Claude Code` rather than `codex` or `claude`, so a script that read the old lower-case names from that text needs updating (#545).
