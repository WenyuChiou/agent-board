- **Terminal board / One-line status** · `agent-board --status` prints the current progress file’s Needs you and Working now counts in one plain line for a shell prompt or tmux. It reads the progress file once and never reads sidecars, writes files or starts a service (#547).
  Tests: `the status line counts what needs you and what is working in one line and writes nothing`, `the status line uses all three languages and an explicit language overrides the installed one`, `the status line for an empty or missing progress file prints zero without creating files`, `status wins over flags that could start services, write files or run a host adapter`, `an unreadable status file fails without printing a misleading zero count`, `the npm launcher forwards status without a build-comparison notice on every poll`.
