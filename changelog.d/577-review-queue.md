- **Contributing / Review queue and flaky tests** · `node scripts/review-queue.mjs` lists the pull requests waiting on a reviewer, smallest first with the hours each has waited, then those that need `main` merged, the approved ones and those waiting on their author. The contributor guide now says how to handle a flaky or slow test (an issue the same day and a fix at its cause, never a longer timeout) and to wait for CI in the background instead of watching it (#577).
  Tests: `a pull request whose Ready comment is for its head and has no verdict after it waits on a reviewer`, `a conflicted or behind pull request is listed as needing main before anything else`, `the reviewer queue lists the smallest pull request first and marks one Ready for more than four hours`, `a verdict for an older head does not count against a Ready for the current head`.
