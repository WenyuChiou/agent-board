- **CI / Plugin on Windows** · A pull request that changes what the plugin loads (hooks and the board bundle, the plugin manifest, package.json, .gitattributes or the test workflow's Claude Code pin) also runs the plugin check on Windows, so a Windows-only load failure is caught before it reaches main (#613).
