- **Codex / Windows hooks** · On Windows, Codex 0.164 runs its hooks through PowerShell, and the hook command setup wrote, every word in double quotes, failed there, so the board got no Codex events. Setup now writes the Node path first without quotes (its short 8.3 name when the path has a space), which PowerShell and cmd both run; a Node path with a space and no short name goes through an encoded PowerShell launch, which costs a PowerShell start. Running setup again replaces an older command; the new command is new to Codex, so on Windows trust the hooks again with setup's `--codex-trust --codex-bin <full path to codex>`, then the same with `--apply` (#623).
  Tests: `on Windows the generated Codex hook command runs through PowerShell and through cmd, with spaces in the worker and progress paths`, `on Windows a Codex hook command for a Node path with no quote-free name runs from PowerShell and cmd through an encoded launch`, `setup replaces a Codex hook command an earlier release wrote with every word quoted, without the person removing it`.
