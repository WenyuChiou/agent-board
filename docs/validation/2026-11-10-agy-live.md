# Live run: board message to an `agy` session, 0.24.3 (#826)

Question: does a message sent from the board's page reach an Antigravity CLI session at its next turn, and what does the board record?

- **Host:** `agy` 1.5.3, Windows 11 (build 26300), the kept test home (not named here), a scratch project folder.
- **Release:** Agent Board 0.24.3, commit `0bf544022fc991a18fb814cab55e3d28516d8267`.
- **Run by:** Claude Code subagent (Claude Sonnet), 2026-11-10. All times are US Eastern, read from the board's message store and from the runner's own clock.
- **Command:** two turns in one headless session, no tools: `agy --input-format stream-json --output-format stream-json -p=` with stdin lines `{"event":"user","message":{"content":"…"}}`. Turn 1 at 11:34:30, turn 2 at 11:35:50. The prompts were synthetic.

## What happened

| Time | Stage |
|---|---|
| 11:34:30 | turn 1 sent: "Hello. Blue or green?" |
| 11:34:48 | the card "Blue or green?" (Antigravity, project "antigravity") was on the board, about 10 s after the turn |
| 11:34:55 | from the page, "Blue", then `Queue for Antigravity's next turn`; the card said "Queued" ("It waits for this session's next turn. It does not wake an idle session.") |
| 11:35:50 | turn 2 sent |
| 11:36:00 | claimed and **accepted** (the hook of turn 2 handed it over; `claimed` and `accepted` within 5 ms) |
| after 11:36:00 (time not recorded) | turn 2's reply: "ACK 4aeffd" and a sentence saying the Agent Board sent the message "Blue" with that token |
| 11:42 | the store still read `accepted` |

Message id prefix `AB-96cfa248…`, nonce `4aeffd`.

## Result

**PASS: accepted at the next turn, which is the last stage for a hook mailbox.**
- The message reached the model at its next turn: the agent printed the ACK line with the nonce.
- The board's record stayed `accepted` six minutes later. The runner first rated this FAIL (no `acknowledged`). The maintainer checked it: for a hook mailbox `accepted` means the hook wrote the message to the host and no ACK is collected (docs/MESSAGING.md), and the card's own text says "Handed to the session at its turn start. No reply is confirmed." So `accepted` is the right end state.
- A small mismatch remains: the delivery text still asks the agent to "Reply first with this line alone: ACK <nonce>", so the agent prints an ACK that nobody reads on hook hosts.
