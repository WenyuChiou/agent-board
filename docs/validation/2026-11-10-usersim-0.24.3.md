Every session is `synthetic`: the installed Codex hook command was run with a hook event on stdin; the Claude Code, Antigravity, Cursor and OpenCode rows and the hand-kept task are blocks written in the file's format.

- **Linux (P2).** The second run's scripts, pointed at the new package and a new empty home `<home>` in a temporary folder, with every home and agent variable pointed into it, `CLAUDE_PROGRESS_FILE` unset, and a PATH with no Windows folder.   - The bare command over SSH was a simulated session in a real pseudo-terminal: SSH_CONNECTION and SSH_TTY set, DISPLAY and WAYLAND_DISPLAY unset. No SSH server is installed in WSL.
