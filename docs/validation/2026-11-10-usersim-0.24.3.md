The real Codex program ran for the trust step only and wrote its own state files in its folder. Every session is `synthetic`: the installed Codex hook command was run with a hook event on stdin; the Claude Code, Antigravity, Cursor and OpenCode rows and the hand-kept task are blocks written in the file's format.
  - Without a terminal to answer in, setup only previews (as the README says).
  - The page was driven in headless Chrome with its own profile folder (1280 and 375 px, Light and Dark). Copy was read back from that browser's clipboard. Timings were taken with the computer otherwise quiet.
- **Linux (P2).** The first run's scripts were replayed. Claude Code, Codex, Antigravity and Cursor are not installed there: their sessions are `synthetic` (the installed hook command run with a hook event on stdin, the agent's own `--report` command, or hand-written blocks). The page was driven from Windows through Playwright (WSL forwards 127.0.0.1).
